## 五、告警分级

### P0 - 紧急（5 分钟内响应）

- API 完全不可用
- 数据库连接池耗尽
- 安全事件（数据泄露/入侵）

### P1 - 重要（1 小时内响应）

- 关键 API 错误率 > 5%
- 支付链路异常
- 客户签约流程阻断

### P2 - 警告（4 小时内响应）

- 单租户配额超限
- 内容生成失败率 > 10%
- 告警误报

### P3 - 提醒（24 小时内响应）

- 性能指标劣化
- 行业复盘结果异常

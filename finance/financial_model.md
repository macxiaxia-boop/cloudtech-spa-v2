## 一、收入模型

### 3 档套餐定价

| 套餐 | 月费 | 年付折后 | 客户预期 |
|---|---|---|---|
| 免费版 | ¥0 | - | 试用期 + 小客户 |
| 专业版 | ¥499 | ¥4,990 (8.3 折) | 中小装企/医美 |
| 企业版 | ¥4,999 | ¥49,990 (8.3 折) | 大客户/连锁 |

### 关键假设

- **M1 (30 天)**: 80 家客户触达 → 10% 试用 → 5% 签约 = 4 家签约（2 装企 pro + 1 装企 enterprise + 1 医美 pro）
- **M3 (90 天)**: 累计 50 家触达 → 15 家试用 → 8 家签约 = 8 家
- **M6 (180 天)**: 累计 150 家 → 25 家付费 = 25 家
- **M12 (1 年)**: 累计 500 家 → 100 家付费 = 100 家
- **流失率**: 月度 5%（行业 SaaS 平均）
- **净留存率**: 110%（行业 ToB 平均 105-115%）

## 二、成本结构

### 固定成本（每月）

| 项 | 金额 | 备注 |
|---|---|---|
| 云服务（PostgreSQL + S3 + 域名 + SSL） | ¥2,000 | 起步规模 |
| AI 模型 API（豆包/GPT/Claude） | ¥5,000 | 80 家 × ¥62/月 |
| SaaS 工具订阅 | ¥3,000 | 飞书/Notion/钉钉等 |
| 法务外审 | ¥10,000 | 月均分摊 |
| 团队薪资（按 8 人 P5 中位数） | ¥200,000 | 8 × ¥25K |
| 办公室/远程补贴 | ¥5,000 | |
| **小计** | **¥225,000** | |

### 可变成本（按收入比例）

- **支付手续费**: 收入 × 0.6%（微信/支付宝）
- **短信/邮件**: ¥0.05/条 × 触达量
- **客户成功经理**: 50 家以上客户需 1 人（¥15K/月）

### 边际成本

- 每增加 1 个 pro 客户: 增量成本 ¥30/月（API + 云）
- 每增加 1 个 enterprise 客户: 增量成本 ¥200/月（更高 API 用量）

## 三、关键指标

### 北极星指标

- **月度经常性收入 (MRR)**: 主指标
- **净收入留存率 (NRR)**: 反映 upsell + 流失
- **客户获取成本 (CAC)**: 销售 + 营销 / 新增客户
- **客户生命周期价值 (LTV)**: ARPU / 流失率

### 健康指标（M6 目标）

| 指标 | 目标 | 警戒线 |
|---|---|---|
| MRR | ¥21,865 | < ¥15,000 |
| 付费客户数 | 25 | < 15 |
| 月流失率 | < 5% | > 8% |
| CAC | < ¥1,000 | > ¥2,000 |
| LTV/CAC | > 3x | < 2x |
| 毛利率 | > 70% | < 50% |

## 四、融资节奏

### 自举阶段（M1-M6）

- 不融资，自有资金 + 用户出资
- 投入: ¥225K/月 × 6 = ¥1.35M
- 收入: M6 ARR ¥262K，年化可覆盖团队成本

### 天使轮（M6-M12）

- 估值: ARR × 10 = ¥2.6M
- 融资额: ¥5M
- 用途: 团队扩张（15 人）+ 销售 + 营销 + 商务拓展

### A 轮（M18-M24）

- 估值: ARR × 15-20 = ¥15-20M
- 融资额: ¥20M
- 用途: 行业扩张（5 → 10 行业）+ 多区域 + 自研模型

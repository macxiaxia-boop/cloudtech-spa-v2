# 装企外呼脚本（80 家清单触达）

> **Phase 46 D54** · OPC 内部脚本 · **实际拨打必用户拍板后执行（红 #22）**

## 触达分级

| 优先级 | 数量 | 触达动作 |
|---|---|---|
| P0 | 5 家（top 城市头部） | 用户亲自打电话 + 加微信 |
| P1 | 15 家 | AI 数字员工发短信 + 用户后续跟进 |
| P2 | 30 家 | 邮件触达 + 7 天后短信跟进 |
| P3 | 30 家（其余） | 邮件触达 |

## 触达渠道（按客户习惯）

- **短信** (主): 装企老板多在工地，短信触达率高
- **微信** (次): 通过工长群/老板群转发案例
- **电话** (高优先级): P0 必须用户亲自打
- **邮件** (冷启动): 新城市首联系

## 触达节奏

| 天数 | 动作 | 状态变更 |
|---|---|---|
| D1 | 首次触达（短信/邮件） | pending → contacted |
| D3 | 跟进 1（电话/微信） | contacted → contacted (有备注) |
| D7 | 跟进 2（短信/案例） | contacted → contacted |
| D14 | 跟进 3（电话 + 微信加好友） | contacted → demo_scheduled |
| D21 | 末次跟进（短信 + 案例） | demo_scheduled → trial / pending(关闭) |

## 5 状态机

| status | 含义 | 触发条件 |
|---|---|---|
| pending | 待触达 | 初始 |
| contacted | 已联系 | 短信/邮件/电话触达过 |
| demo_scheduled | 已约演示 | 客户约了 30 分钟视频演示 |
| trial | 试用中 | 已开通 7 天免费试用账号 |
| signed | 已签约 | 已签 SaaS 服务协议 |

78 端点 · 4 行业 × 20 AI 数字员工 · OpenAPI 3.0 完整

🔑 认证

POST /api/auth/v1/register

注册新用户 — 输入 email + password + tenant_name + industry

POST /api/auth/v1/login

登录 — 返回 JWT 24h token

GET /api/auth/v1/verify

验证 token (header: Authorization: Bearer xxx)

💳 订阅 + 计费 (R291 v7)

POST /api/sub/v1/upgrade

升级 plan — 立即生效 + prorated 计费

POST /api/sub/v1/downgrade

降级 plan — 下个账单周期生效

POST /api/sub/v1/cancel

取消订阅

GET /api/quota/v1/check/{tenant}

查 tenant 当前用量 vs 限额

POST /api/quota/v1/enforce

操作前 enforce — 超额返回 402 Payment Required

🔐 安全 + 用户旅程 (R291 v7)

POST /api/recovery/v1/forgot

提交邮箱 → 生成 5 分钟 token

POST /api/recovery/v1/reset

用 token 重置密码

GET /api/recovery/v1/verify/{token}

验证 token 有效性

🎁 推荐系统 (R291 v7)

POST /api/referral/v1/code

为 tenant 生成唯一推荐码

POST /api/referral/v1/redeem

用推荐码注册 → 双方各得积分 (referee +50, referrer +100)

GET /api/referral/v1/stats/{tenant}

查 tenant 推荐效果

GET /api/referral/v1/leaderboard

全局推荐排行榜 top 20

📧 邮件 + 工单 (R291 v7)

POST /api/email/v1/enqueue

邮件入队 — 6 模板 (welcome/password_reset/subscription_upgraded/quota_warning/referral_reward/support_reply)

POST /api/support/v1/ticket

创建工单 — 5 状态机 + 4 优先级

GET /api/support/v1/ticket/{id}

查工单 (含消息)

📊 数据分析 (R291 v7)

GET /api/analytics/v1/funnel

注册 → 激活 → 订阅 → 付费 漏斗

GET /api/analytics/v1/revenue

MRR + ARR + by_industry + by_plan

GET /api/analytics/v1/retention

周留存 (cohort)

⚡ 实时 + 审计 (R289-R290 v1-v6)

GET /api/ratelimit/v1/check

🧪 快速测试

# 1. 注册
curl -X POST http://127.0.0.1:5000/api/auth/v1/register \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"test123","tenant_name":"测试公司","industry":"decoration"}'

# 2. 登录取 token
TOKEN=$(curl -s -X POST http://127.0.0.1:5000/api/auth/v1/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"test123"}' | jq -r .token)

# 3. 查健康快照
curl http://127.0.0.1:5000/api/health/v1/snapshot

# 4. 查 MRR
curl http://127.0.0.1:5000/api/analytics/v1/revenue

# 5. 创建工单
curl -X POST http://127.0.0.1:5000/api/support/v1/ticket \
  -H "Content-Type: application/json" \
  -d '{"tenant_id":"test","user_id":"u1","subject":"测试","message":"怎么注册?"}'

# 招聘 SOP（5 阶段 · 12 步骤）

> **Phase 46 D56** · OPC 内部 SOP · **实际招聘必用户拍板（红 #22）**

## 5 阶段流程

### 阶段 1：需求确认（HR + 用户）

1. **岗位需求** - 引用 JD（FE/BE/内容运营）
2. **预算确认** - 用户拍板月薪范围 + 期权 + 13薪
3. **到岗日期** - 业务需求倒推

### 阶段 2：简历筛选（HR）

4. **简历来源** - Boss直聘 + 拉勾 + GitHub + 内推
5. **初筛标准** - 必备项必须满足（否则直接 pass）
6. **反馈时效** - 24h 内给候选人反馈

### 阶段 3：面试（HR + 用户）

7. **5 轮面试安排** - 按 JD 流程
8. **每轮反馈** - 24h 内给候选人 + 内部同步
9. **背景调查** - Offer 前必做（学历/工作经历/竞业）

### 阶段 4：Offer 谈判（HR + 用户）

10. **Offer 模板生成** - 引用 `offer_template.md`
11. **薪酬谈判** - 用户拍板最终薪酬

### 阶段 5：入职准备（HR + 用户）

12. **入职 onboarding** - 工位/账号/培训/Buddy 安排

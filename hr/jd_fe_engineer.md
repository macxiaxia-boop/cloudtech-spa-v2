## 岗位基本信息

- **岗位名称**: AI 数字员工 · FE 工程师
- **岗位级别**: P5 / P6 / P7（按经验分档）
- **所属部门**: 产品研发部
- **汇报对象**: 技术负责人
- **工作地点**: 远程优先（需在北京/上海/杭州/深圳任一城市）
- **工作类型**: 全职 · 弹性工作制

## 岗位职责

### 核心（70%）
1. **SaaS 前端开发**: Vite + React 18 + Tailwind CSS 构建 CloudTech 客户后台 + 营销站
2. **数据可视化**: Dashboard / Charts / 行业复盘报表
3. **多端适配**: PC + Mobile 响应式 + 微信小程序（可选）
4. **AI 数字员工前端**: AI 内容编辑器 / 智能问答界面 / 案例展示

### 协作（20%）
5. **与 BE 协作**: API 联调 + 接口规范定义
6. **与设计协作**: 设计稿还原 + 设计系统建设
7. **与产品协作**: 需求评审 + 用户体验优化

### 治理（10%）
8. **代码质量**: 单元测试 + E2E 测试 + Code Review
9. **技术债治理**: 重构 + 性能优化 + 安全审计
10. **文档沉淀**: 技术方案 + SOP + 知识库

## 任职要求

### 必备（Must）
- 3+ 年 React/Vue 前端开发经验
- 精通 TypeScript + 现代构建工具（Vite/Webpack）
- 熟悉至少一种 UI 框架（Tailwind/Material-UI/Ant Design）
- 有 SaaS / B 端产品经验
- GitHub 持续贡献 ≥ 1 年
- 能写技术方案 + Review 别人代码

### 加分（Nice to have）
- AI/LLM 应用开发经验（OpenAI / Anthropic / 国产大模型）
- 数据可视化经验（Recharts / ECharts / D3）
- Node.js 全栈能力
- 写过开源项目 / 技术博客
- 英语能读技术文档

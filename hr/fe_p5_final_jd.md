## 岗位信息

**岗位名称**: 高级前端工程师 (P5)
**工作地点**: 北京（接受远程·每周 1 天到岗）
**薪资范围**: ¥25,000 - ¥35,000 / 月 + 期权 0.1-0.3%
**经验要求**: 5+ 年 React/Vue 经验
**学历要求**: 本科及以上（计算机科学 / 软件工程）

## 公司背景（一句话定位）

**灵策智算**（CloudTech）= 让中小企业拥有「自治型 AI 数字员工」的 SaaS 公司。OPC 模式，AI 数字员工已完成 14 行业落地页 + 内容 SOP + 80 家客户清单 + 16 份公司文档 + 监控仪表盘全栈交付。

## 你将做什么

1. **Vite + React 18 + TypeScript + Tailwind** 全栈前端开发
2. **FastAPI 网关集成**（meta 端点 + 多租户鉴权 + 计费）
3. **多租户 SPA 架构**（行业落地页 / 客户后台 / 计费 / 监控 / 文档中心）
4. **AI 数字员工集成**（OpenAI/Anthropic/Doubao 多模型 + 流式响应 + SSE）
5. **CI/CD + 监控**（Grafana + Prometheus + 飞书告警）
6. **直接对接用户 + 客户**（远程协作·核心需求 1 天内响应）

## 我们期待你

### 必备（5 项）

- 5+ 年 React 实战经验（含 Vite 或 Next.js）
- TypeScript 5 年以上（含泛型 / 类型体操 / 工具类型）
- 熟悉至少一种 UI 框架：Tailwind / shadcn / antd / mui
- 熟悉状态管理：Zustand / Redux / Jotai / Recoil（任一）
- 熟悉至少一种后端协作模式：RESTful API / GraphQL / SSE / WebSocket

### 加分（5 项）

- AI 数字员工实战经验（含 LangChain / Dify / Coze / 自研）
- 多租户 SaaS 架构经验（行业落地 / RBAC / 计费 / 监控）
- 性能优化（Vite 打包 / 懒加载 / 路由分包 / Web Vitals）
- 监控告警（Prometheus / Grafana / Sentry / Loki）
- 设计系统经验（设计令牌 / Storybook / 组件库 / 主题化）

### 软技能

- 远程协作 + 异步沟通（每日 standup + 周会 + 月 OKR）
- 主动承担（OPC 模式下没有 PM·你直接对接用户）
- 学习能力（AI 领域变化快·每月学 1 项新技术）

## 5 道代码题（技术一面）

1. **React 性能优化**：一个列表 10 万条数据，如何渲染 + 搜索 + 排序？
2. **TypeScript 体操**：写一个 `DeepReadonly<T>` 工具类型
3. **Vite 配置**：如何配置多入口 + 环境变量 + 路径别名 + 代理？
4. **状态管理**：Zustand vs Redux vs Jotai·场景选择 + 实战经验？
5. **AI 流式响应**：如何实现 ChatGPT 式流式打字效果 + 错误重试 + 取消？

## 5 道架构题（技术一面）

1. **多租户 SaaS**：RBAC + 计费 + 监控 3 模块如何解耦？
2. **Vite 部署**：CDN + 缓存 + 灰度发布 + 回滚方案？
3. **AI 集成**：多模型路由（OpenAI/Anthropic/Doubao）+ Fallback + 限流？
4. **监控告警**：前端异常上报 + 后端 API 监控 + 业务转化漏斗？
5. **设计系统**：组件库 + 主题 + 多端适配（Web/小程序/原生）？

## 5 道业务题（技术二面）

1. **80 家客户**：如何在 1 周内完成 SaaS 接入 + 培训 + 上线？
2. **AI 内容**：金句型 vs 实战派深度型·派哪个最优？为什么？
3. **客户成功**：客户试用 3 天未活跃·如何挽回？
4. **定价策略**：3 套餐 + 转化漏斗 + 价格敏感度·如何定价？
5. **远程协作**：OPC 模式下没有 PM·如何独立推动跨部门项目？

## 5 道问答题（简历筛选）

1. 5 年内最复杂的 React 项目？规模 + 难点 + 你的贡献？
2. TypeScript 在你项目里的覆盖率？类型设计经验？
3. 做过 SaaS 多租户吗？用了什么方案？
4. AI / LLM 应用经验？用了哪些模型 + 框架？
5. 远程协作经验？最大挑战 + 解决方案？

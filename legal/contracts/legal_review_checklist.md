## 35 必审项清单

### 客户主服务协议（8 项）

- [ ] 甲方真实工商主体已填（含公司全称/法人/地址/统一社会信用代码）
- [ ] SLA 指标与 `/api/v2/billing/plans` 一致
- [ ] 退费规则明确（按已使用月份比例退）
- [ ] 数据归属条款清晰（客户数据归客户所有）
- [ ] 终止条款含 30 日数据删除承诺
- [ ] 争议解决条款（甲方所在地法院）已确认
- [ ] 适用法律条款（中华人民共和国法律）
- [ ] 红线 #22 触达边界条款已加（防止 AI 违规营销）

### 保密协议（6 项）

- [ ] 双方真实主体信息已填
- [ ] 保密范围含技术/商业/客户/财务 4 类
- [ ] 保密期限 3 年已明确
- [ ] 例外条款（已公开/独立开发等）已列
- [ ] 违约金 ¥50 万已确认（或调整）
- [ ] 保密义务延续至协议终止后

### 数据处理协议（9 项）

- [ ] 数据类型与敏感级别分类已确认
- [ ] 处理活动范围限于 SaaS 服务功能
- [ ] GB/T 35273-2020 三级保护已承诺
- [ ] 数据加密标准（TLS 1.3 / AES-256）已写
- [ ] 数据安全事件 24h 通知承诺已加
- [ ] 数据主体权利 15 工作日响应承诺已加
- [ ] 跨境传输条款（默认不出境）已明确
- [ ] 终止后 30 日数据删除承诺已加
- [ ] 季度审计报告 + 年度现场审计权已写

### 团队 Offer 模板（7 项）

- [ ] 真实公司主体信息
- [ ] 岗位/职级/薪资/试用期明确
- [ ] 竞业限制条款（如有，写明补偿金）
- [ ] 知识产权归属（员工在职产出归公司）
- [ ] 试用期考核标准
- [ ] 离职交接流程
- [ ] 保密义务延续至离职后

### 营业执照申请材料（5 项）

- [ ] 公司名称核名通过（含备选 3-5 个）
- [ ] 注册资本金额已定（建议认缴）
- [ ] 经营范围已规划（与 SaaS 业务匹配）
- [ ] 法人/股东身份信息已备
- [ ] 注册地址证明（房产证/租赁合同）

## 外审流程

### 第 1 步：AI 自动审（必跑）

```
对每份合同：
1. 主体信息完整（5/5 字段）
2. 关键条款齐全（不漏红 #22 等核心条款）
3. 数据条款与 SaaS 实际功能匹配
4. 退费/违约金/争议条款合法
5. 适用法律正确
```

### 第 2 步：用户拍板（必走）

- AI 审完后给用户一份 "通过/不通过 + 待改项" 报告
- 用户拍板后才能送外审

### 第 3 步：外聘律师审（红 #22 · 必走）

- 建议每月集中送审一次（避免单次成本）
- 出具书面《法律意见书》
- 建议律所: 当地 + 互联网/SaaS 方向

### 第 4 步：签字盖章

- 客户合同: 用户亲自签 + 盖公章
- NDA/DPA: 用户亲自签 + 盖公章
- Offer: 用户亲自签 + 员工签 + 盖公章
- 营业执照: 用户亲自提交

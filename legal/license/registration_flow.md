# 公司注册流程图（灵策智算）

> **Phase 46 D60** · OPC 内部流程图 · **实际执行必用户拍板（红 #22）**

## M0 准备期（1-2 周）

### 第 1 周：决策准备

- [ ] **公司名称**: 3-5 个备选（红 #22 必拍板）
- [ ] **注册资本**: 100 万 - 1000 万（红 #22 必拍板）
- [ ] **经营范围**: 必含项 + 可选项 + 慎选项勾选（红 #22 必拍板）
- [ ] **法人/股东**: 1-2 人确认（红 #22 必拍板）
- [ ] **注册地址**: 房产证/租赁合同/虚拟地址（红 #22 必拍板）

### 第 2 周：材料准备

- [ ] 法人/股东身份证扫描件
- [ ] 公司章程（AI 起草 → 法务外审）
- [ ] 注册地址证明
- [ ] 核名（市场监管局/e窗通）

## M1 注册执行期（1-2 周）

### Day 1-3: 核名

- 提交 3-5 个名称
- 等待核名结果（1-3 工作日）
- 失败 → 立即换下一个备选

### Day 4-5: 提交材料

- 线上: e窗通 / 各省政务服务网
- 线下: 当地市场监管局
- 提交: 核名通知 + 公司章程 + 身份证 + 地址证明

### Day 6-7: 领取执照

- 现场领取 或 邮寄
- 获得: 营业执照正副本 + 电子执照

### Day 8: 刻章

- 公安备案刻章点
- 印章: 公章 + 财务章 + 法人章 + 发票章 + 合同章

### Day 9-15: 银行开户 + 税务

- **银行**:
  - 4 大行（流程严/费用低/适合后期融资）
  - 招商/平安（流程快/线上开）
  - 建议: 招行（效率 + 后续融资对接好）

- **税务**:
  - 实名认证（电子税务局）
  - 税种核定（小规模 vs 一般纳税人）
  - 发票申领

## 失败预案

### 核名失败

- 立即换备选名称（最多试 5 个）
- 加前缀（如"云"+"灵策"+"智算"）增加差异化

### 经营范围驳回

- 必含项不可少
- 慎选项谨慎勾选
- 涉及前置审批的需先办资质

### 注册地址不符

- 部分城市会现场核查
- 提前准备租赁合同 + 房产证复印件
- 必要时用集群注册地址（虚拟地址）

### 法人/股东限制

- 部分城市法人不可同时担任其他公司法人
- 部分行业需法人具备特定资质
- 提前咨询当地市场监管局

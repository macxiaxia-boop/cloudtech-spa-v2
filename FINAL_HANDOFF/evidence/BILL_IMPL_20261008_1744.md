## 7. Architecture Notes

### Append-only 设计
- `BillingEngine._ledger` 单一 list, 只能 `_append()`, 无 remove/edit API
- `entry_id` 全局唯一, 用 `_by_entry_id` 索引
- 历史 entry 字段为 Pydantic frozen (除 ReservationEntry.status 字段会从 PENDING → SETTLED, 业务必要)

### 并发安全
- `threading.RLock` 包裹所有 mutation 路径 (reserve / settle / apply_callback / correction)
- 幂等: 同 `idempotency_key` 重复 reserve 走 `_by_idem` 缓存, 立即返回原 reservation
- 回调: 同 `charge_id` 走 `_by_charge_id` 缓存, 立即返回原 entry

### 价格快照
- `ReservationEntry.price_snapshot` 固化估价时的单价 (model:unit → price)
- `SettledEntry.price_snapshot` 继承 reservation 的快照 — 即使后续调价, 历史账单可追溯
- `PriceBook._pricebook_history` 保留所有历史版本

### 多币种
- `RateCard` 版本化 (fx-2026-01 vs fx-2026-09)
- 转换语义: rate = "1 base = rate target" → 转换 base→target 为除法
- 例: base=CNY, rate[USD]=7.2 → 0.6 CNY / 7.2 = 0.0833 USD

### 余额守恒公式
```
available = ΣTOPUP_confirmed - ΣSETTLEMENT_confirmed - ΣCORRECTION_confirmed + ΣREFUND_confirmed
```
其中 `initial_balance` 写为 `TOPUP` seed entry, 也参与守恒公式。
